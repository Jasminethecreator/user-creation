# Creating Users in Microsoft Azure's Entra ID
 
## Objective
 
Create and configure a new user account in Microsoft Entra ID, setting up account properties correctly on first creation.
 
## Scenario
 
This lab simulated onboarding a new employee by creating their user account directly in Entra ID, assigning basic account details before any roles, licenses, or group memberships were applied.
 
## Tasks Completed
 
- Filled out the new user form for Kyle Roberts, setting the display name, password, and account properties (city, job title: HR Representative).
- Created the account with no group or role assignments applied at creation.
- Verified the account was created successfully as an enabled Member-type user.

## What I Learned
 
This lab reinforced how much account setup happens before a user ever gets access to a single tool display name, properties, and account type all need to be right at creation, since roles, licenses, and groups all build on top of this initial profile.

- Microsoft Azure Entra ID
- Windows 11
