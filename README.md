# Microsoft Entra ID — User Creation

## Objective

Create and configure a new user account in Microsoft Entra ID and verify that the account was successfully created with the intended user properties.

## Tools & Environment

- Microsoft Entra ID
- Microsoft Azure portal
- Windows 11

## Steps Performed

1. Opened Microsoft Entra ID and started the new user creation process.
2. Entered the account information for **Kyle Roberts**, including the display name and password.
3. Added profile information, including:
   - City
   - Job title: **HR Representative**
4. Created the account without assigning groups, licenses, or administrative roles during the initial setup.

## Verification

Verified that the new account appeared in Microsoft Entra ID as:

- **Enabled**
- **User type: Member**
- Configured with the intended profile information
